# NaNLMind_CLOCKED

CLOCKED by Rezolve.ai integration, evidence codec, NaN16 mapping profile, scratch protocol, learning design and evaluation.

## Canonical architecture

See [CLOCKED × NaNLMind × HERMES — Deep Integration Brainstorm](docs/CLOCKED_HERMES_BRAINSTORM.md).

## Project boundary

- **CLOCKED** supplies hosted structured-reasoning observations.
- **NaNLMind** remains the single mathematical memory and learning substrate.
- **HERMES** provides the conversational surface, orchestration and dedicated CLOCKED mode.
- **NaNNet / NaNROUTER** provide authenticated transport, address resolution and policy.
- **Koyeb** provides the persistent gateway; the six-runner ring performs distributed head execution.
- **NaN16** owns guest-side protocol semantics and deterministic transformations.

This repository is currently design-first. The canonical document explicitly marks pseudocode as conceptual and does not claim runtime implementation or deployment. No API keys, private user corpora or raw service responses belong in Git.
